TareasPlus - mejoras de tareas y móvil

- Edición completa: título, descripción, lista, responsables/chips, fecha y prioridad.
- Al añadir nuevos responsables al editar, se notifica solo a los nuevos asignados.
- Tarjetas de resumen navegables.
- Descripción visible en la lista de tareas.
- Menú móvil se cierra al elegir una opción/lista.
