# TareasPlus colaborativo

Incluye:
- listas/proyectos compartidos
- miembros por lista
- invitaciones por correo
- uno o varios responsables por tarea
- Mis tareas / Todas / Completadas
- sincronización Firestore

## Instalación
1. Sustituye index.html en GitHub Pages.
2. Sustituye las reglas de Firestore por firestore.rules y publica.
3. Crea una lista e invita a otro correo.
4. El invitado debe iniciar sesión con ese mismo correo.
